Calculation Settings

These are the engineering constants and core calculation formulas behind the Calculations panel. Tweak any of them and the Spec Sheet recalculates immediately — your changes are saved in this browser.

General constants
Total Pallet Height — Half Pallet / Box on HP offset

Total Pallet Height = (Layers/Pallet × Unit Height) × 2 + offset, for Packaging Type = "Half Pallet" or "Box on HP". This offset is now a single flat value (no longer split by Pallet Type) — edit it under General constants below as "Total height offset — Half Pallet / Box on HP (mm)".

Container Type Library — max stack height & weight allowance

Edit any container type's name, max stack height, and (optional) flat weight allowance, or add brand-new container types — they appear immediately in the Container's Type dropdown on the Spec Sheet and as a new column in the Pallet Library table below. Leave Weight Allowance blank to fall back to the Container's Destination based allowance (General constants below), exactly like 40 HC has always worked; 20 FT instead uses a flat cap.

Container TypeMax Stack Height (mm)Weight Allowance (Ton) — blank = use Destination
Pallet Library — dimensions, strap offsets & pallets/container

Edit any pallet's name and size, or add brand-new pallet types — they appear immediately in the Pallet Type dropdown on the Spec Sheet. Length (A) × Width (B) also auto-fill the packing footprint, and Strap Length = ((Pallet Height + A) × 2 × Straps/Side + (Pallet Height + B) × 2 × Straps/Side) ÷ 1000. Pallets/Container has one editable column per Container Type above — exactly like the original 40 HC constants, now extended to every type.

Custom Calculated Fields

Add your own formulas, written like an Excel equation. Click a field chip below to insert a reference, then combine with + − × ÷ ^ ( ) and functions like SUM, AVERAGE, MIN, MAX, ABS, SQRT, ROUND, ROUNDUP, ROUNDDOWN, IF, AND, OR, POWER. Example: =({palletWeight}*{palletPerContainer})/1000
